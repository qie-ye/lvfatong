## 一、V3.6 版本概述

### 1.1 版本定位

V3.6 聚焦于**团队协作能力**的建设，支持律师团队协作办案、案件共享、任务分配和实时沟通，提升团队办案效率。

### 1.2 核心目标

| 目标 | 说明 | 量化指标 |
|------|------|----------|
| 团队协作 | 支持律师团队组建和管理 | 支持 50+ 团队 |
| 案件共享 | 案件信息团队内共享 | 实时同步 <1s |
| 任务分配 | 案件任务拆分和跟踪 | 支持 10+ 任务类型 |
| 实时沟通 | 团队内部消息通知 | 消息延迟 <500ms |

### 1.3 更新内容

| 模块 | 内容 | 工期 | 优先级 |
|------|------|------|--------|
| 团队管理 | 创建团队、成员管理、角色权限 | 1.5周 | ⭐⭐⭐ |
| 案件协作 | 案件共享、任务分配、进度跟踪 | 2周 | ⭐⭐⭐ |
| 消息通知 | 站内消息、实时通知、@提醒 | 1.5周 | ⭐⭐ |
| 协作工具 | 评论、标注、文件共享 | 1周 | ⭐ |

**总工期**：6 周

## 二、模块一：团队管理（1.5周）

### 2.1 目标

支持律师团队的创建、管理和权限控制，为协作功能提供基础架构。

### 2.2 功能清单

| 功能 | 说明 | 实现方式 |
|------|------|----------|
| **创建团队** | 律师可创建办案团队 | 团队信息、Logo、描述 |
| **邀请成员** | 通过链接/手机号邀请 | 邀请码机制 |
| **成员管理** | 成员列表、移除成员 | CRUD 操作 |
| **角色权限** | 所有者、管理员、成员 | RBAC 权限控制 |
| **团队设置** | 团队信息编辑、解散团队 | 设置页面 |

### 2.3 数据模型

#### 团队表 (teams)
```sql
CREATE TABLE teams (
    id BIGINT AUTO_INCREMENT PRIMARY KEY,
    name VARCHAR(100) NOT NULL COMMENT '团队名称',
    description TEXT COMMENT '团队描述',
    logo_url VARCHAR(500) COMMENT '团队Logo',
    owner_id BIGINT NOT NULL COMMENT '创建者ID',
    invite_code VARCHAR(20) UNIQUE COMMENT '邀请码',
    max_members INT DEFAULT 50 COMMENT '最大成员数',
    status VARCHAR(20) DEFAULT 'ACTIVE' COMMENT '状态：ACTIVE/DISBANDED',
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    INDEX idx_owner_id (owner_id),
    INDEX idx_invite_code (invite_code),
    INDEX idx_status (status)
);
```

#### 团队成员表 (team_members)
```sql
CREATE TABLE team_members (
    id BIGINT AUTO_INCREMENT PRIMARY KEY,
    team_id BIGINT NOT NULL COMMENT '团队ID',
    user_id BIGINT NOT NULL COMMENT '用户ID',
    role VARCHAR(20) DEFAULT 'MEMBER' COMMENT '角色：OWNER/ADMIN/MEMBER',
    joined_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    UNIQUE KEY uk_team_user (team_id, user_id),
    INDEX idx_team_id (team_id),
    INDEX idx_user_id (user_id)
);
```

#### 团队邀请表 (team_invitations)
```sql
CREATE TABLE team_invitations (
    id BIGINT AUTO_INCREMENT PRIMARY KEY,
    team_id BIGINT NOT NULL COMMENT '团队ID',
    inviter_id BIGINT NOT NULL COMMENT '邀请人ID',
    invitee_id BIGINT COMMENT '被邀请人ID',
    invitee_phone VARCHAR(20) COMMENT '被邀请人手机号',
    status VARCHAR(20) DEFAULT 'PENDING' COMMENT '状态：PENDING/ACCEPTED/REJECTED/EXPIRED',
    expires_at DATETIME COMMENT '过期时间',
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    INDEX idx_team_id (team_id),
    INDEX idx_invitee_id (invitee_id),
    INDEX idx_status (status)
);
```

### 2.4 API 接口

| 方法 | 路径 | 说明 |
|------|------|------|

| PUT | `/api/v1/teams/{id}` | 更新团队信息 |

| PUT | `/api/v1/teams/{id}/members/{userId}/role` | 修改成员角色 |
| DELETE | `/api/v1/teams/{id}/members/{userId}` | 移除成员 |

## 三、模块二：案件协作（2周）

### 3.1 目标

支持团队成员协作办案，包括案件共享、任务分配和进度跟踪。

### 3.2 功能清单

| 功能 | 说明 | 实现方式 |
|------|------|----------|
| **案件共享** | 案件共享给团队成员 | 权限控制 |
| **任务分配** | 案件任务拆分和分配 | 任务管理 |
| **进度跟踪** | 任务状态更新和跟踪 | 状态机 |
| **协作看板** | 看板视图展示任务 | Kanban Board |
| **案件日志** | 操作日志和审计 | 日志记录 |

### 3.3 数据模型

#### 案件协作表 (case_collaborations)
```sql
CREATE TABLE case_collaborations (
    id BIGINT AUTO_INCREMENT PRIMARY KEY,
    case_id BIGINT NOT NULL COMMENT '案件ID',
    team_id BIGINT NOT NULL COMMENT '团队ID',
    shared_by BIGINT NOT NULL COMMENT '分享人',
    permission VARCHAR(20) DEFAULT 'VIEW' COMMENT '权限：VIEW/EDIT/ADMIN',
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    UNIQUE KEY uk_case_team (case_id, team_id),
    INDEX idx_case_id (case_id),
    INDEX idx_team_id (team_id)
);
```

#### 任务表 (tasks)
```sql
CREATE TABLE tasks (
    id BIGINT AUTO_INCREMENT PRIMARY KEY,
    case_id BIGINT COMMENT '关联案件ID',
    team_id BIGINT NOT NULL COMMENT '所属团队ID',
    title VARCHAR(200) NOT NULL COMMENT '任务标题',
    description TEXT COMMENT '任务描述',
    assignee_id BIGINT COMMENT '负责人ID',
    assigner_id BIGINT NOT NULL COMMENT '分配人ID',
    priority VARCHAR(20) DEFAULT 'MEDIUM' COMMENT '优先级：LOW/MEDIUM/HIGH/URGENT',
    status VARCHAR(20) DEFAULT 'TODO' COMMENT '状态：TODO/IN_PROGRESS/REVIEW/DONE',
    due_date DATE COMMENT '截止日期',
    completed_at DATETIME COMMENT '完成时间',
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    INDEX idx_case_id (case_id),
    INDEX idx_team_id (team_id),
    INDEX idx_assignee_id (assignee_id),
    INDEX idx_status (status),
    INDEX idx_due_date (due_date)
);
```

#### 任务评论表 (task_comments)
```sql
CREATE TABLE task_comments (
    id BIGINT AUTO_INCREMENT PRIMARY KEY,
    task_id BIGINT NOT NULL COMMENT '任务ID',
    user_id BIGINT NOT NULL COMMENT '评论人ID',
    content TEXT NOT NULL COMMENT '评论内容',
    parent_id BIGINT COMMENT '父评论ID（回复）',
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    INDEX idx_task_id (task_id),
    INDEX idx_user_id (user_id)
);
```

#### 案件日志表 (case_activity_logs)
```sql
CREATE TABLE case_activity_logs (
    id BIGINT AUTO_INCREMENT PRIMARY KEY,
    case_id BIGINT NOT NULL COMMENT '案件ID',
    user_id BIGINT NOT NULL COMMENT '操作人ID',
    action VARCHAR(50) NOT NULL COMMENT '操作类型',
    details JSON COMMENT '操作详情',
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    INDEX idx_case_id (case_id),
    INDEX idx_user_id (user_id),
    INDEX idx_created_at (created_at)
);
```

## 四、模块三：消息通知（1.5周）

### 4.1 目标

实现团队内部的实时消息通知，支持@提醒、任务通知等。

### 4.2 功能清单

| 功能 | 说明 | 实现方式 |
|------|------|----------|
| **站内消息** | 系统通知、团队消息 | 消息中心 |
| **实时通知** | WebSocket 实时推送 | STOMP 协议 |
| **@提醒** | 提及成员时通知 | 解析 @mention |
| **消息已读** | 已读/未读状态 | 状态管理 |
| **通知设置** | 通知偏好设置 | 用户设置 |

### 4.3 数据模型

#### 消息表 (messages)
```sql
CREATE TABLE messages (
    id BIGINT AUTO_INCREMENT PRIMARY KEY,
    team_id BIGINT COMMENT '团队ID',
    sender_id BIGINT NOT NULL COMMENT '发送者ID',
    receiver_id BIGINT COMMENT '接收者ID（私信）',
    channel_type VARCHAR(20) NOT NULL COMMENT '渠道类型：TEAM/TASK/CASE/PRIVATE',
    channel_id BIGINT COMMENT '关联ID（任务ID/案件ID）',
    content TEXT NOT NULL COMMENT '消息内容',
    message_type VARCHAR(20) DEFAULT 'TEXT' COMMENT '消息类型：TEXT/SYSTEM/FILE',
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    INDEX idx_team_id (team_id),
    INDEX idx_sender_id (sender_id),
    INDEX idx_receiver_id (receiver_id),
    INDEX idx_channel (channel_type, channel_id),
    INDEX idx_created_at (created_at)
);
```

#### 消息已读表 (message_read_status)
```sql
CREATE TABLE message_read_status (
    id BIGINT AUTO_INCREMENT PRIMARY KEY,
    message_id BIGINT NOT NULL COMMENT '消息ID',
    user_id BIGINT NOT NULL COMMENT '用户ID',
    read_at DATETIME COMMENT '已读时间',
    UNIQUE KEY uk_message_user (message_id, user_id),
    INDEX idx_user_id (user_id)
);
```

#### 通知表 (notifications)
```sql
CREATE TABLE notifications (
    id BIGINT AUTO_INCREMENT PRIMARY KEY,
    user_id BIGINT NOT NULL COMMENT '接收者ID',
    type VARCHAR(50) NOT NULL COMMENT '通知类型',
    title VARCHAR(200) NOT NULL COMMENT '通知标题',
    content TEXT COMMENT '通知内容',
    related_type VARCHAR(50) COMMENT '关联类型',
    related_id BIGINT COMMENT '关联ID',
    is_read BOOLEAN DEFAULT FALSE COMMENT '是否已读',
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    INDEX idx_user_id (user_id),
    INDEX idx_is_read (is_read),
    INDEX idx_created_at (created_at)
);
```

### 4.4 API 接口

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/v1/messages` | 获取消息列表 |
| POST | `/api/v1/messages` | 发送消息 |
| GET | `/api/v1/messages/channels` | 获取频道列表 |
| GET | `/api/v1/notifications` | 获取通知列表 |
| PUT | `/api/v1/notifications/{id}/read` | 标记已读 |
| PUT | `/api/v1/notifications/read-all` | 全部已读 |
| GET | `/api/v1/notifications/unread-count` | 未读数量 |
| WebSocket | `/ws/team/{teamId}` | 团队实时消息 |
